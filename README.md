Application Retrieval
1. While on the repository clock on the 'Code' button and copy the link provided there
2. Open your Android Studio IDE
3. Click on 'Clone Repository' on the top right corner
4. Add the copied link onto the 'URL'position
5. Then click on 'Clone'
6. At this point it will pull every file related to the application.

Running the application
1. click on the green 'play' button in the top of the IDE which is positioned next to the 'app' button at the top
