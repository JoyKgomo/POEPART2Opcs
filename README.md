Application overview 

We have collaborated in creating a mobile application that uses Kotlin as the main component's language and uses Room DB as the application's Database on which the inserted information is stored. This is a budgeting application that implements adding an expense/income, creating a budget according to a category, an overview of the expenses on the landing page, as well as adding a card with the ability to take pictures of receipts or possibly the items when adding them as expenses. 

Application Retrieval
1. While on the repository clock on the 'Code' button and copy the link provided there
2. Open your Android Studio IDE
3. Click on 'Clone Repository' on the top right corner
4. Add the copied link to the 'URL' slot
5. Then click on 'Clone'
6. At this point it will pull every file related to the application.

Running the application
1. Click on the green 'play' button at the top of the IDE, which is positioned next to the 'app' button at the top

Using the application
1. Start by signing up so your information is stored in the Database and you can sign in with your information later.
2. Then you will end up on the landing page, but there are two recorded entries, so to add an expense/income, click on the button with the '+'
3. Once you click on this button, you will be taken to the create category
